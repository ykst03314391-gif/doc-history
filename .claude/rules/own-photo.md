# 自分で撮った写真を載せるとき

管理人が現地で撮った写真（城跡・古戦場・ゆかりの地）をサイトに載せるときの確認と手順。表記の欄は `docs/schema-castle.md` の Photo（`own`・`taken`）。

## 載せる前に確かめる

写真を受け取ったら、**組み込む前に**次の表を順に確かめ、結果を管理人に短く伝える。「写真を見て確かめる」項目は自分で見て判断し、「管理人に聞く」項目は写真からはわからないので、答えをもらってから組み込む。1つでも引っかかったら、その写真は載せずに理由を伝え、撮り直し・ぼかし・切り抜きなどの案を出す。

| 項目 | 確かめ方 | 載せてよい／だめの目安 |
|---|---|---|
| 撮った場所の撮影・掲載の決まり | 管理人に聞く | 屋外の城跡・石垣・建物の外観・屋外の銅像は、ふつう載せてよい（著作権法46条）。資料館・博物館・寺社の**中**は、撮影禁止・「SNSは可、Webサイトは不可」・商用不可の決まりがあることが多い。このサイトはアフィリエイトを置くので商用とみなされうる。決まりがわからなければ、施設に問い合わせてもらう |
| 展示物（屏風・古文書・仏像など） | 写真を見て確かめる | 主題として写っていれば、上の決まりを特に確かめる。所蔵者の許可が要ることがある |
| 説明板・解説パネル | 写真を見て確かめる | 写り込み程度ならよい。文章が読める形で説明板が主題になっていれば載せない（切り抜くか、内容を要約して本文に自分の言葉で書く） |
| 写っている人 | 写真を見て確かめる | 顔がわかる人がいれば、ぼかすか切り抜くか、撮り直しを頼む |
| 位置情報（EXIF） | 自分で確かめる | 組み込むときに必ず消す（下の手順）。自宅や宿など、場所を知られたくないところが写っていないかも見る |
| ドローンで撮ったもの | 管理人に聞く | 史跡の上空は許可が要ることが多い。許可を得たかを確かめる |
| 戦国期の姿でない建物 | 写真を見て確かめる | 復興天守・模擬天守・復元の門などは `note` に必ず書く |

## 組み込みの手順

1. 画像を `assets/img/castles/<id>.jpg`（合戦は `battles/`）に幅720pxで、`thumbs/<id>.jpg` に160×160で書き出す。Pillow で開き、**EXIF を付けずに**保存する（`save` に `exif` を渡さない）。書き出したあと、EXIF が残っていないことを確かめる。元の写真ファイルはリポジトリに入れない。
2. `index.json` の `photo` を `{ "src", "thumb", "caption", "note"?, "own": true, "taken": "2026-11" }` で書く。`source` は書かない。`author` は管理人が名前を出したいときだけ書く（省略すると「ぱぱねこの戦国見立て」）。`license` は書かない（省略すると `js/photo.js` が CC BY 4.0 を出す。転載可・撮影者名は「ぱぱねこの戦国見立て」と管理人が決めた）。
3. それまで Commons の写真を使っていた城・合戦なら、差し替えてよいか管理人に聞いてから差し替え、使わなくなった画像ファイルを消す。
4. 記事の冒頭画像（`image`）に使うときは、`credit` を「撮影：ぱぱねこの戦国見立て（2026年11月）」とし、`license` に "CC BY 4.0"、`licenseUrl` に "https://creativecommons.org/licenses/by/4.0/deed.ja" を書く。
