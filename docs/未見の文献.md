# ネットで読めない、確かめるべき文献の一覧

ネット（Wikisource・NDL 次世代デジタルライブラリー・CiNii・各機関のサイトなど）で当たれるものは `reference/` に取り込み済み（`docs/sources.md`）。この文書は、その外にあって**本・図書館・取り寄せでしか中身を確かめられない文献**を、当たる優先順にまとめたもの。

- 作り方：人物・合戦・城・大名家の `sources`（本は未見・孫引きと書いたもの）、`toVerify` の `checkWith`、記事の `references`、論文版（`drafts/`）の「要確認」から拾った（2026-11-05 時点）。
- 「関わるところ」は、その本で片づく要確認の場所。手に取ったら、そこを直し、`sources` の note から「本は未見」「頁は Wikipedia 経由」を外す（`docs/sources.md` の決まり）。
- 書誌は、データに書いてあるものをそのまま写した。**「※」を付けたものは、データに書誌がなく Claude の知識で補ったもの**で、刊行元・巻次は手に取る前に NDL サーチで確かめる。
- 読む手段の略号：**買**＝購入、**公**＝公共図書館（無ければ相互貸借で取り寄せ）、**大**＝大学図書館、**複**＝NDL の遠隔複写（利用者登録が要る）、**館**＝NDL の館内限定、**送**＝NDL の個人向け送信（登録してログインすれば自宅で読める。対象かどうかは資料ごとに確かめる）。

## 付：ネットにあるが、まだ使い切っていないもの

「ネットで当たれるものは網羅」と言うために、残っているものを書いておく。

- **東京大学史料編纂所のデータベース**（大日本史料・古記録フルテキストなど）… 大日本史料の綱文・史料の画像、大日本古記録（言経卿記など）の本文が引ける。一括取得はできないので `reference/` には入れていないが、上の『大日本史料』第十一編・言経卿記の要確認は、ここで片づく見込みがある。
- **NDL の個人向け送信**（要登録）… 次世代デジタルライブラリーに OCR 全文が無い資料でも、送信の対象なら自宅で画像を読める。『御湯殿上日記』『寛政重修諸家譜』『大友家文書録』の刊本などが対象か、NDL サーチで確かめる。登録とログインは管理人がする。
- **原本画像との照合**（NDL デジタルコレクション）… 多聞院日記・信長公記（pid 781192〜4）・常山紀談・名将言行録・公卿補任など、OCR・翻刻の字を画像で確かめる残り。ネットで済む作業なので、この一覧には入れていない（各ページの `toVerify` に書いてある）。
