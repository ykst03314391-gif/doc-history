# 出典・原典の当たり先メモ

DBの「仮置きデータ」を、実際の原典で裏取りしていくための調査ノート。
見つけた使える原典は、人物データの `sources`（`sourceId` で本文参照）へ正しく紐付けていく。

> 大前提：**一次史料**（当事者・同時代の記録＝信長公記・フロイス日本史・古記録など）と、
> **二次史料**（後世の編纂・研究＝軍記物・江戸の史書・研究書）を区別して扱う。
> **小説・随筆は「史料」ではない**（近代人がどう描いたかの資料にはなるが、事実の典拠にはできない）。

---

## 青空文庫（aozora.gr.jp）調査 ― 2026-07-07

**結論：戦国時代の「一次史料」として使えるテキストは無い。**
青空文庫にあるのは、著作権の切れた**近代作家の歴史小説・随筆**が中心。原典（信長公記・日本外史・甲陽軍鑑・太閤記の翻刻）は見当たらない。

### 見つかったもの（すべて創作・評論 → 事実の典拠には不可）

| 作品 | 著者 | 性格 | 使い道 |
|---|---|---|---|
| 織田信長 | 坂口安吾 | 歴史小説（1948、完結） | ×事実の典拠。△「近代の信長像」を論じる記事の参照 |
| 新書太閤記 | 吉川英治 | 歴史小説 | ×事実の典拠。△同上（秀吉像） |
| 川中島合戦 | 菊池寛 | 読み物・小説 | ×事実の典拠。△同上（謙信・信玄像） |
| 古事記 | 太安万侶ほか | 古典（上代） | 戦国とは無関係 |

> 検索で `信長公記`『日本外史』『甲陽軍鑑』『太閤記（甫庵）』の**翻刻は青空文庫にヒットせず**。
> これらは漢文・古文の史料で、青空文庫の収録対象からほぼ外れている。

### 判断

青空文庫は**「近代人が戦国をどう描いたか」を論じる記事（考察）用の素材**としては使えるが、
**DBの事実を裏取りする原典としては使えない**。裏取りは別の場所に当たる必要がある。

### ★ 信長公記（太田牛一）― 一次史料　【sourceId: `shincho-koki`】

織田信長の旧臣・太田牛一が書いた信長の一代記。**戦国研究の代表的な一次史料**。
機械可読の翻刻テキストが入手でき、底本もパブリックドメインで、**このサイトで実際に裏取りに使える**ことを確認した（2026-07-07）。

**裏取りチェーン**

1. 原典（一次史料）：太田牛一『信長公記』
2. 底本（パブリックドメインの刊本）：**我自刊我書**（甫喜山景雄 刊、1881／明治14年）＝町田本系
3. スキャン画像（インターネット公開）：NDLデジタルコレクション
   - 上 `pid 781192` / 中 `pid 781193` / 下 `pid 781194`（`https://dl.ndl.go.jp/pid/<pid>`）
4. 翻刻テキスト（機械可読・**これを使う**）：
   - 新字版：`https://ja.wikisource.org/wiki/信長公記`（旧字を新字化・検索向き）
   - 旧字版：`https://ja.wikisource.org/wiki/信長公記/我自刊我書`（底本に忠実）
5. **ローカル固定スナップショット（今後の裏取りはこれを直接grepする）**：
   `reference/wikisource/shincho-koki.txt`（新字版 revid 218442 を 2026-07-07 取得、約15.4万字、首巻〜巻之十五）。
   Web版は更新されうるので凍結コピーを持つ。取得は Wikisource の parse API（`action=parse&prop=text`）で全文取得→タグ除去。詳細は [`../reference/README.md`](../reference/README.md)。

**収録範囲・注意**
- **首巻（入洛前）＋巻之一〜巻之十五まで完全収録**（永禄11年〜天正10年）。天正10年の「信長公本能寺にて御腹めされ候事」「中将信忠卿二条にて歴々御生害之事」も含む（＝信長・信忠の最期の典拠に使える）。Wikisource上に未完注記なし。
- 内容は**信長の事績が中心**。信長・信忠・光秀・秀吉らの「信長期」の記述には典拠になるが、**上杉謙信の生涯や武田・上杉の内政などの典拠にはならない**（＝別史料が必要。今 `uesugi-kenshin` 等に付いている信長公記ラベルは不適切なので外す）。
- 翻刻はパブリックドメイン扱い。引用時は「太田牛一『信長公記』（我自刊我書本、Wikisource 翻刻）」の形で底本を明示する。

### △ 甲陽軍鑑 ― 二次史料（要史料批判）　【sourceId: `koyo-gunkan`】

武田信玄・勝頼期の武田氏をめぐる軍学書。高坂昌信に仮託され、小幡景憲が編纂・成立させたとされる。
**川中島の合戦や上杉謙信の記述を含む**ため、謙信・武田まわりの裏取り素材になる（2026-07-07 確保）。

- ローカル：`reference/wikisource/koyo-gunkan.txt`（Wikisource 全60品第を結合、約52万字。川中島56・信玄1549・謙信287 ヒット）
- 底本：内藤傳右衛門・温故堂 刊本（Wikisource 新字版）

## ★ NDL 次世代デジタルライブラリー（OCR全文）ルート ― Wikisource に無い史料の第2の入口

Wikisource に無い明治〜昭和初期の**PD活字本**は、NDL「次世代デジタルライブラリー」（`lab.ndl.go.jp/dl`）の**OCR全文API**から機械可読テキストで引ける（2026-07-07 に実地検証。常山紀談で成功）。

**取得手順**

1. NDLサーチ等で対象史料の PD活字本を探し、その **`lab.ndl` book id** を得る（`https://lab.ndl.go.jp/dl/book/{id}` が開けるもの）。
2. 書誌：`https://lab.ndl.go.jp/dl/api/book/{id}`（JSON。title/volume/page数/目次）。
3. **OCR全文：`https://lab.ndl.go.jp/dl/api/book/fulltext/{id}`** → ページ別 `{id}_NNNNNNN.txt`（＋.json）を詰めた **ZIP** が返る。`.txt` を番号順に結合すれば全文。
4. 画像原本：`https://dl.ndl.go.jp/pid/{pid}`（最終確認用。IIIFマニフェスト `https://dl.ndl.go.jp/api/iiif/{pid}/manifest.json` は画像のみでOCRは無い）。

**注意**

- **OCRなので要校正**。明治活字本は概ね良好だが誤認識・未認識字（`〓`）が混じる。重要引用は原本画像で確認。
- **次世代デジタルライブラリー収録分（＝全文検索対応のPD資料）に限る**。全NDLではない。
- **多巻物は巻ごとに book id が別**。全巻化には各巻を取得して結合する（例：常山紀談は上=778101/中=778102/下=778103 を結合＝`reference/ndl/jozan-kidan.txt`）。

> これで、Wikisource に無い軍記も lab.ndl に収録があれば同様に引ける。使う際は Wikisource 分と同じく `reference/` に来歴付きで固定する。

## 運用ルール（確定分）

1. 原典を確認できたら、この文書の表に「確認済み」として底本・URL とともに記録する。
2. **再利用する原典はローカルに固定スナップショットを取り**、`reference/` に来歴付きで置く（都度ダウンロードしない）。取得法は2系統：(a) Wikisource parse API（`action=parse&prop=text&formatversion=2`）で全文JSON→タグ除去、(b) Wikisourceに無ければ NDL 次世代デジタルライブラリーの OCR全文ZIP（上記「NDLルート」）。NDL由来は OCR/要校正を明記。
3. 裏取りは `reference/` の原典を全文検索（grep）して行う。**人名・地名は表記ゆれに注意**（例：桶狭間は本文に無く `義元`／別綴り地名で書かれる）。
4. 裏が取れた記述を人物データの `sources` に登録し、該当フィールドに `sourceId`（＋可能なら巻・項目）を紐付ける。校正品質が低い原典は旧字版・NDL画像で最終確認。
5. 典拠にならない事柄には無理に紐付けない。既存の誤ラベル（例：`uesugi-kenshin` の信長公記）は外す。
6. ページの `sources` に新しい**史料**（歴史的な著作・記録・書状など）を足したら、公開用の出典一覧 `data/sources.json`（`sources.html` で表示）にも登録する。`level`（1=一次／2=二次／3=三次）・`yomi`（50音順の並び順に使う）・`usedIn`（使用ページ）を付ける。**近年の研究書・論文・調査報告・Webページは載せない**（各ページの出典欄にだけ書く）。
7. 裏取りできた記述から順に、その人物ページの「仮置きデータ」注記を外す（全記述が済んだページ単位で解除）。

## 研究・論文の参照（考察記事の裏付け）

原典が「事実の裏取り」なら、**論文・研究書は「解釈・最新研究の裏付け」**。特に考察記事の「近年の研究では〜」を、曖昧な一般論でなく**実在の研究で示す**ために使う（＝かつての `kanetada-kenkyu` のような曖昧ラベルの正しい解決）。

**探し方・引ける度合い（2026-07-07 検証）**

- **CiNii Research（cir.nii.ac.jp）／NDLサーチ**：実在論文の**書誌（著者・誌名・巻号・年・頁）が確実に取れる** → `sources`(type:"論文")／`references` に正式引用できる。
- **J-STAGE・大学リポジトリ**：オープンアクセスの**HTML本文**は WebFetch で読める見込み。
- **PDF論文**：本文の自動抽出は不可（WebFetch は要約止まり、Read も poppler 未導入でPDF不可）。書誌引用に留めるか手動確認。
- 新しい論文は著作権保護中 → **書誌引用はOK、全文の大量転載は不可**。

**出典欄での区分（2026-10-22 決定）**：ページの `sources` の `primary` は次の4つで書き分ける。

| `primary` | 中身 | `type` の例 |
|---|---|---|
| 一次資料 | 同時代の日記・書状・石塔銘など | 史料 |
| 二次資料 | 後世の軍記・編纂物（森家先代実録など） | 史料・書籍 |
| 研究 | 研究者の著書・論文・研究者本人の寄稿。**事実そのものではなく「誰がどう読んだか」の典拠**なので、説の持ち主を note に明記する | 研究書・論文・寄稿 |
| （付けない） | Wikipedia などの概要 | ネット記事 |

**出典欄の表示**：`primary` は塗りつぶしのバッジで、色は区分ごとに固定（一次資料＝朱、二次資料＝黄土、研究＝藍）。`type` は枠だけのバッジ（色を持たない）。出典欄の頭に凡例を出す（人物・合戦・城ページ共通）。

- **小説家・ライターの一般向け記事、ドラマ解説は出典にしない**（ドラマ由来の情報が混ざりやすい。例：秀長の正室の名「慶」は史料に無い）。
- 頁数を Wikipedia などから引き写したときは、note に「頁は〇〇経由で、本は未見」と書く。手元で確かめたら外す。
- 研究は `data/sources.json`（出典一覧）には載せない（運用ルール6）。
