# 判断待ち

管理人の判断を待っている事柄の一覧。Claude はセッションの始めにこのファイルを読み、残っている項目を管理人に短く伝えてから作業に入る。判断が済んだ項目は、反映したうえでこのファイルから消す（経緯はコミットメッセージに残す）。

（2026-11-02 時点。人物を主役・脇役・名前だけの3段階で扱う方針にしたあとのもの。方針は CLAUDE.md の「進め方」）

## 豊臣秀長の「ぱぱねこのまとめ」（lens.answer）

人物ページの最後の論点の下の「ぱぱねこのまとめ」に、記事3本の「先に答えを言うと」から Claude が作った答えのたたき台を入れてある（「半分は当たり、半分は外れている」で始まる文）。管理人が直すか、そのままでよいと決めたら、この項を消す。見立て（`lens.view`）を足すなら管理人が書く（まとめの中の答えのあとに出る）。

## 次に決めること

- **次の主役**：次に考察を書く人物を誰にするか。決まったら、その人物の詳細ページを仕上げ、リンクに要る脇役だけを概要で作る。それまで人物・合戦・城の新しいページは作らない（これまでの「新しく作るページ」の候補表は、この方針で取り下げた）。
