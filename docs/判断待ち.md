# 判断待ち

管理人の判断を待っている事柄の一覧。Claude はセッションの始めにこのファイルを読み、残っている項目を管理人に短く伝えてから作業に入る。判断が済んだ項目は、反映したうえでこのファイルから消す（経緯はコミットメッセージに残す）。

## 豊臣秀長の「ぱぱねこのまとめ」（lens.answer）

人物ページの最後の論点の下の「ぱぱねこのまとめ」に、記事3本の「先に答えを言うと」から Claude が作った答えのたたき台を入れてある（2026-11-05、管理人の指示で、書き出しを「兄を支えたという意味では、補佐役だった。ただ、兄の陰に控えた温厚な補佐役ではない。」に、「兄との関係：」の段落をその意味の「補佐」は当たるという形に改めた。残りの段落はたたき台のまま）。論点④「「名補佐役」は、いつ、だれが言い出したのか？」（像の出どころ）を足し、記事「秀長の「名補佐役」は、いつ、だれが言い出したのか」（`hidenaga-hosayaku-origin`）を書いたのに合わせて、まとめの末尾の「像の出どころ：」の段落を、像の中身は江戸後期の藤堂家の記録『聿脩録』（1818年序）、広めたのは大正の歴史家、「補佐役」の名は1985年の堺屋太一、という形のたたき台に直した。管理人が直すか、そのままでよいと決めたら、この項を消す。見立て（`lens.view`）を足すなら管理人が書く（まとめの中の答えのあとに出る）。
