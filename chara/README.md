# chara/ ― キャラクターの設定置き場（サイト非配信）

記事の漫画・挿絵・マスコットに使うキャラクターの元絵と決まりを置く。`drafts/`・`reference/` と同じ編集者用の資料で、ページからは読み込まない。サイトに出す絵は、これまでどおり `assets/img/manga/`・`assets/img/illust/` などに置く。

## ぱぱねこ（`papaneko/`）

管理人が描いているオリジナルの猫キャラで、**管理人本人（自画像）**でもある。サイトに出てくる**すべてのキャラ・イメージの絵・マスコットの元**にする（2026-11-04 決定）。いまの元絵はラフで、清書は管理人が手描きする。

### 変えないところ（顔）

- 横に広い大きな頭
- **両耳とも丸い**（ラフ絵で片耳がとがって見えるのは描きのゆれ。とがらせない）
- ふだんの顔は、閉じた笑い目（への字を逆にした弧）と ω の口（目と口は、下の「表情」で描き分けてよい）
- 小さな鼻
- ひげは左右3本ずつ
- **眉は描かない**（2026-11-04 決定。気持ちは目と口と、添える印で出す）

### 表情（喜怒哀楽）

眉を使わず、**目と口の形と、顔の外に添える印**で喜怒哀楽を出す（2026-11-04 決定）。頭の形・耳・鼻・ひげは変えない。見本は `chara/papaneko-hyojo.svg`（Claude の仮の SVG。挿絵・漫画で表情を付けるときはここから目と口を写す）。

| 表情 | 目 | 口 | 添える印 |
|---|---|---|---|
| ふだん | 閉じた笑い目（∩） | ω | なし |
| 喜 | 高く大きな笑い目（∩） | ω の下に開いた口 | 頬の斜線、金のきらめき |
| 怒 | 内側が下がる一文字（＼／） | ω を返した形 | 朱の怒りの印 |
| 哀 | 外側が下がる一文字（／＼） | 小さく返した ω | 藍の涙（心配・困りは汗にしてもよい） |
| 楽 | ゆるんだ目（∪） | ω | 頬の斜線、音符 |

- 目は閉じたまま（線）で描き、黒目は入れない。
- 印の色は CLAUDE.md の色に合わせる（朱 #9b2d20・金 #b08d33・藍 #2f5d7c）。印のほかは塗らない。
- 小さな絵で目と口が読めないときは、印と姿勢（伏せる・のけぞるなど）で補う。

### 色

当面は**塗らない**（墨の線だけで、毛は地色のまま）。毛の色・柄を決めたらここに書く。

### 使い道

- **漫画**：登場するキャラはすべてぱぱねこを元にする。
  - 聞き手（現代から当時の人物に話を聞く役）は、ぱぱねこ本人。
  - 当時の人物は、ぱぱねこの派生キャラとして描き、兜・烏帽子・衣装・持ち物で誰かを見分けられるようにする。顔の決まりは崩さない。
  - 服を着せない（基本形の四つ足など）ときは、被り物・持ち物の**印と名札の両方**で見分ける（2026-11-04 決定）。誰かを確かに伝えるのは名札で、挿絵には必ず付ける（小さな絵では印が読めないため）。印は名札に重ねる補いで、同じ絵に並んだときの見分けと、漫画で2コマ目以降の名札を省くのに使う（名札は初めて出るコマに付ける）。決まった印：**豊臣秀吉＝高い立烏帽子と、朱の紐で首に下げた金の瓢箪**（場面に合えば瓢箪の旗・馬印を持たせてもよい）、**豊臣秀長＝低い折烏帽子（先を後ろへ折る）と、藍の紐で首に下げた小豆**（「大和大納言」から大納言小豆のしゃれ。兄の瓢箪と対にする）。名札は秀吉を朱、秀長を藍の字にする。**織田信長＝南蛮帽子**（黒の丸い山につば、朱の帯、金の羽根。両耳を隠さないよう頭の上に小さめにのせる）。身分の印：**僧＝首に下げた数珠**。家の印：**武田＝頭に金の二本角の飾り**（絵でよく見る鬼のような角の兜の見立て。武田の家臣にも付ける）。ひな型は見舞いの絵（`assets/img/illust/hidenaga-mimai.svg`）。
  - 体の形の目安：漫画の基本は2頭身（小さなコマでも表情が見える）。立って話す・説明する場面は4頭身、アップや決めのコマは半身、のんびりした場面は基本形の四つ足。
- **挿絵**：場面を描いた絵（キャプションに「（想像図）」）にも、たとえの絵（「（イメージ）」）にも使う。想像図では、当時の人物をぱぱねこの派生キャラで描き、年・場所・建物・調度・衣装は時代に合わせる（考証はキャラ以外のところで守る）。ひな型は「秀長は「補佐役」で満足していたのか」の見舞いの絵（`assets/img/illust/hidenaga-mimai.svg`。基本形の四つ足で服は着せず、立烏帽子の兄が、折烏帽子で額に手ぬぐいをのせて伏す弟の頭へ前足を伸ばす）。
- **管理人の顔**：記事の書き手の表示、本文の筆者の意見の囲み「ぱぱねこの見立て」、「先に答えを言うと」と論点の結論の囲みの札、サイト紹介の「書いている人」に、顔だけの絵 `assets/img/chara/papaneko-face.svg` を出す（いまは Claude の仮の SVG。清書ができたら差し替える）。
- **マスコット**：サイト紹介・404・一覧の空き欄など、サイトの顔として置く。

### 作るとき

- Claude の仮の SVG は、上の顔の決まりに合わせて描く。
- Gemini で作るときは、CLAUDE.md の【画風】に加え、`papaneko/` の元絵（清書ができたら清書）を添え、【シーン】に「添えた絵の猫のキャラを、顔の形（横に広い頭・丸い両耳・閉じた笑い目・ω の口・左右3本のひげ・眉なし）を変えずに描く」と書く。
