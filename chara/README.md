# chara/ ― キャラクターの設定置き場（サイト非配信）

記事の漫画・挿絵・マスコットに使うキャラクターの元絵と決まりを置く。`drafts/`・`reference/` と同じ編集者用の資料で、ページからは読み込まない。サイトに出す絵は、これまでどおり `assets/img/manga/`・`assets/img/illust/` などに置く。

## ぱぱねこ（`papaneko/`）

管理人が描いているオリジナルの猫キャラで、**管理人本人（自画像）**でもある。サイトに出てくる**すべてのキャラ・イメージの絵・マスコットの元**にする（2026-11-04 決定）。いまの元絵はラフで、清書は管理人が手描きする。

### 元絵

| ファイル | 形 | 位置づけ |
|---|---|---|
| `papaneko/ぱぱねこ.png` | 四つ足。横に長い胴、短い足4本、しっぽが後ろで上に立つ | **基本形** |
| `papaneko/ぱぱねこ_2頭身.png` | 二本足で立つ、2頭身 | アレンジ |
| `papaneko/ぱぱねこ_4頭身.png` | 二本足で立ち、腰に手、4頭身 | アレンジ |

体の形・姿勢は、この3枚くらいのアレンジまでは変えてよい。

### 変えないところ（顔）

- 横に広い大きな頭
- **両耳とも丸い**（ラフ絵で片耳がとがって見えるのは描きのゆれ。とがらせない）
- 閉じた笑い目（への字を逆にした弧）
- 小さな鼻と ω の口
- ひげは左右3本ずつ

### 色

当面は**塗らない**（墨の線だけで、毛は地色のまま）。毛の色・柄を決めたらここに書く。

### 使い道

- **漫画**：登場するキャラはすべてぱぱねこを元にする。
  - 聞き手（現代から当時の人物に話を聞く役）は、ぱぱねこ本人。
  - 当時の人物は、ぱぱねこの派生キャラとして描き、兜・烏帽子・衣装・持ち物で誰かを見分けられるようにする。顔の決まりは崩さない。
  - 体の形の目安：漫画の基本は2頭身（小さなコマでも表情が見える）。立って話す・説明する場面は4頭身、アップや決めのコマは半身、のんびりした場面は基本形の四つ足。
- **挿絵**：場面を描いた絵（キャプションに「（想像図）」）にも、たとえの絵（「（イメージ）」）にも使う。想像図では、当時の人物をぱぱねこの派生キャラで描き、年・場所・建物・調度・衣装は時代に合わせる（考証はキャラ以外のところで守る）。ひな型は「秀長は「補佐役」で満足していたのか」の見舞いの絵（`assets/img/illust/hidenaga-mimai.svg`。烏帽子の兄が、額に手ぬぐいをのせて伏す弟の頭へ手を伸ばす）。
- **管理人の顔**：記事の書き手の表示、本文の筆者の意見の吹き出し「ぱぱねこの見立て」、サイト紹介の「書いている人」に、顔だけの絵 `assets/img/chara/papaneko-face.svg` を出す（いまは Claude の仮の SVG。清書ができたら差し替える）。
- **マスコット**：サイト紹介・404・一覧の空き欄など、サイトの顔として置く。

### 作るとき

- Claude の仮の SVG は、上の顔の決まりに合わせて描く。
- Gemini で作るときは、CLAUDE.md の【画風】に加え、`papaneko/` の元絵（清書ができたら清書）を添え、【シーン】に「添えた絵の猫のキャラを、顔の形（横に広い頭・丸い両耳・閉じた笑い目・ω の口・左右3本のひげ）を変えずに描く」と書く。
